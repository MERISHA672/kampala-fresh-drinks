# 🥤 Kampala Fresh Drinks

### Refresh Your World

## About the Project

Kampala Fresh Drinks is a modern, responsive beverage company website concept inspired by Kampala, Uganda. It showcases a fictional drinks brand through an attractive interface, product displays, and a contact form.

The project demonstrates frontend web development skills using HTML, CSS, and JavaScript.

## Features

- **Responsive Design:** Adapts to mobile phones, tablets, and desktop screens.
- **Modern Landing Page:** Includes a hero section with a clear call to action.
- **Product Showcase:** Displays three fictional beverage concepts.
- **Navigation Menu:** Links to the Home, Our Drinks, About, and Contact sections.
- **Contact Form:** Validates required fields before displaying a confirmation message.
- **Smooth Scrolling:** Provides smooth navigation between website sections.
- **Dynamic Footer:** Automatically displays the current year.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/MERISHA672/kampala-fresh-drinks.git
   ```

2. Open the project folder:

   ```bash
   cd kampala-fresh-drinks
   ```

3. Open `index.html` in your web browser.

No additional dependencies are required.

## Contact Form

The contact form checks that the required fields are completed and displays a confirmation message. It is a frontend demonstration only; messages are not sent to a server or stored in a database.
